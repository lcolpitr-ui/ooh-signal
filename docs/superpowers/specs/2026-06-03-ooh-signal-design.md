# OOH Signal — 户外广告投放信号情报系统 设计文档

## 系统定位

帮户外广告从业者**发现哪些品牌正在释放投放信号**，AI 自动打分排序，让销售优先跟进高意向客户。

类 AIHOT 的网页展示形式，暗色主题，卡片式时间线。

## 核心功能

### 1. 信号时间线（首页）
- 卡片式展示，每条信号包含：
  - 品牌名称 + 行业标签
  - 信号类型标签（扩张/融资/产品/竞品/政策/行业）
  - 信号摘要（AI 生成）
  - AI 投放可能性评分（0-100）
  - 推荐理由（AI 生成）
  - 原文链接
  - 采集时间

### 2. AI 打分引擎
根据以下维度自动计算投放可能性：
- 信号类型权重（融资 > 扩张 > 产品发布 > 竞品对标 > 行业动态 > 政策）
- 品牌规模（上市公司/头部品牌 > 中小企业）
- 历史投放行为（有户外广告历史的品牌加分）
- 行业特征（快消、汽车、地产等高投放行业加分）
- 信号强度（多条同品牌信号叠加加分）

### 3. 分类筛选
- 按行业：快消、汽车、3C、美妆、金融、地产、教育、医疗、餐饮、零售等
- 按信号类型：扩张/融资/产品/竞品/政策/行业
- 按评分区间：80+（高优先）、60-80（中优先）、60 以下（低优先）
- 按时间：今日/本周/本月

### 4. 搜索
- 按品牌名搜索
- 按关键词搜索信号内容

### 5. 品牌库
- 按行业分组的品牌列表
- 每个品牌卡片显示：品牌名、行业、近期信号数量、最新评分、历史评分趋势

### 6. 每日日报
- 每日 8:00 自动生成
- 汇总过去 24 小时的高分信号（60+）
- 按评分降序排列
- 可通过 RSS 订阅

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | Next.js 14+ (App Router) | 对齐 AIHOT |
| UI | Tailwind CSS + 暗色主题 | 轻量、可定制 |
| 后端 | Next.js API Routes | API 层 |
| 数据采集 | Python 脚本 | RSS 解析 + 网页爬取 |
| AI 处理 | LLM API（Gemini Flash 免费 / OpenAI） | 打分 + 推荐理由生成 |
| 数据库 | SQLite | 轻量起步，后期可迁移 |
| 定时任务 | GitHub Actions Cron | 每小时采集一次 |
| 部署 | Vercel（前端）+ GitHub Actions（采集） | 免费方案 |
| RSS 输出 | 生成 feed.xml | 支持订阅 |

## 数据模型

### Signal（信号）
```typescript
interface Signal {
  id: string;
  brandName: string;        // 品牌名
  industry: string;         // 行业
  signalType: string;       // 信号类型: expansion/funding/product/competitor/policy/industry
  title: string;            // 标题（AI 生成）
  summary: string;          // 摘要（AI 生成）
  sourceUrl: string;        // 原文链接
  sourceName: string;       // 来源名称
  score: number;            // 投放可能性评分 0-100
  reason: string;           // 推荐理由（AI 生成）
  publishedAt: string;      // 原文发布时间
  collectedAt: string;      // 采集时间
  tags: string[];           // 标签
}
```

### Brand（品牌）
```typescript
interface Brand {
  id: string;
  name: string;             // 品牌名
  industry: string;         // 行业
  scale: string;            // 规模: large/medium/small
  isListed: boolean;        // 是否上市公司
  signalCount: number;      // 信号总数
  latestScore: number;      // 最新评分
  website: string;          // 官网
  socialMedia: {            // 社交媒体账号
    weibo?: string;
    xiaohongshu?: string;
    douyin?: string;
    wechat?: string;
  };
}
```

## AI 打分逻辑

### 信号类型基础分
| 信号类型 | 基础分 |
|---------|--------|
| 融资上市 | 80 |
| 品牌扩张 | 70 |
| 产品发布 | 60 |
| 竞品对标 | 55 |
| 行业动态 | 50 |
| 政策场景 | 45 |

### 调整因子
- 上市公司：+15
- 历史有户外投放：+10
- 高投放行业（快消/汽车/地产/3C）：+10
- 多信号叠加（同品牌 3 条以上）：+10
- 信号来源权威性（官方公告 > 媒体报道 > 社交媒体）：+5
